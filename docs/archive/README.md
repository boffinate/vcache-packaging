# Archived notes and plans

Everything in this directory is superseded or historical: wave-by-wave implementation notes for steps whose closing report is now the entry point, plans that were implemented or overtaken by later decisions, and diagnostic notes whose incident is closed. Files are retained, with their original names, for two reasons: their ideas may return, and they are the provenance trail behind decisions and mechanisms that are still live. Nothing here is normative — `SCOPE.md`, `AGENTS.md`, and the top-level `docs/` notes are the current record.

Archived files were moved here verbatim. Relative links between two archived files still resolve; a relative link from an archived file to a note that stayed in `docs/` does not (prepend `../`). Git history has the full context for every file, including its original location.

Curation record: [`docs/20260730_1714_note_docs-curation.md`](../20260730_1714_note_docs-curation.md) lists every file kept, archived, or deleted, with reasons.
